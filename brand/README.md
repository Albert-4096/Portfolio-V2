# alberyt brand kit

One mark for every project: a **peak** (the A of Albert, the Retezat ridge), cut by a **contour** band where an A's crossbar would be, and ended by a **cursor** block (the prompt from the old favicon).

Everything is generated by `build.py` from one 24-unit grid. Change the constants at the top and rerun; nothing in `dist/` or in the site's favicons is drawn by hand.

```
python3 -m pip install fonttools brotli cairosvg
python3 brand/build.py
```

It writes `brand/dist/` and the site's own `assets/favicon.svg` and `assets/apple-touch-icon.png` (Retezat colourway), so the site can't drift from the kit. The wordmark is outlined from the site's self-hosted IBM Plex Mono 500 in `/fonts`.

## Files in `dist/`

| File | Use |
|---|---|
| `alberyt-mark.svg` | The mark, 32 px and up. Peak = `currentColor`, cursor = `var(--mark-signal)` |
| `alberyt-mark-small.svg` | Below 32 px: the same mark without the contour band |
| `alberyt-mark-mono.svg` | One colour (stamps, print, laser) |
| `alberyt-mark-animated.svg` | Blinking cursor; stops under `prefers-reduced-motion` |
| `alberyt-wordmark.svg` | `alberyt` + a one-cell cursor |
| `alberyt-lockup.svg` | Mark + wordmark, the peak as tall as the capitals |
| `tiles/<system>-<theme>.svg` | App-icon tiles for Retezat, Atelier, Dosar, Signal, Marquee and orar, dark and light; the `-favicon` variants use the small cut |
| `icons/*.svg`, `icons/sprite.svg` | 17 UI icons on the same grid (2-unit stroke, square caps, mitred joins). Plain HTML: `<svg><use href="sprite.svg#i-arrow-right"/></svg>` |
| `icons.json` | The same icons as path data, for generating a component module (orar's `src/lib/icons.tsx` is made from it) |
| `orar/` | orar.alberyt.xyz's favicon (light, dark, auto), maskable icon and PNGs |

## Branding a new project

1. **Tile.** Pick the project's design system from `../design-systems/`. The tile takes three of its tokens, `--bg` for the field, `--text` for the peak and `--accent` for the cursor, plus the system's corner radius. Add a row to `SYSTEMS` in `build.py` if the project has its own palette.
2. **Own glyph.** A project with a symbol of its own (orar's departures poster) keeps it and carries the cursor in the bottom-right of its safe area, in the project's accent. That block is the signature; don't add the peak as well.
3. **Chrome.** The project's wordmark ends in the cursor (`0.42em × 0.13em`, on the baseline), and its footer signs off with the small mark linking to alberyt.xyz.
4. **Small sizes.** Below 32 px use the small cut, and draw favicons on a whole-pixel grid (orar's is 16 units).
